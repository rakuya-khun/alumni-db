# Alumni DB Management System

Offline-first Electron desktop app for managing alumni survey data from CE, CpE, and EE programs.

---

## Prerequisites

- [Node.js](https://nodejs.org/) (LTS)
- [pnpm](https://pnpm.io/) — install via `npm install -g pnpm`

---

## Setup

```bash
pnpm install
```

---

## Scripts

| Command | What it does |
|---------|-------------|
| `pnpm dev` | Opens live dev window with hot reload (daily workflow) |
| `pnpm build` | Compiles everything to `out/` (no .exe) |
| `pnpm build:exe` | Compiles + packages into a Windows `.exe` installer in `release/` |
| `pnpm lint` | Run ESLint |
| `pnpm format` | Run Prettier |

---

## Development Workflow

1. Run `pnpm dev` — an Electron window opens with live reload
2. Edit code in `src/` (UI) or `electron/` (backend), save, and see changes instantly
3. Repeat until the feature/fix is done

---

## Building the .exe for Your Client

When you're ready to deliver:

```bash
pnpm build:exe
```

This does two things:
1. **Compiles** TypeScript + bundles React into the `out/` folder
2. **Packages** everything into a Windows installer

The output goes to:

```
release/Alumni DB Setup x.x.x.exe
```

Send that `.exe` to your client. They double-click it to install.

### Updating the .exe

Every time you make changes:

1. Develop and test with `pnpm dev`
2. Run `pnpm build:exe` again
3. A new `.exe` is generated in `release/` with your latest changes
4. Send the new `.exe` to your client

## Smoke Test

Run this after cloning or before starting work to verify everything is configured:

```bash
node tests/smoke-test.cjs
```

Checks 68 items: config files, dependencies, build output, security settings, and project structure.

---

## Project Structure

```
electron/          → Main process (Node.js backend: DB, IPC, auth, integrations)
src/               → Renderer process (React UI, state, routing)
shared/            → Contracts between both processes (types, schemas, IPC channels)
resources/         → Build resources (app icon, etc.)
out/               → Compiled output (generated by build)
release/           → Packaged .exe installer (generated by build:exe)
```
